---
title: "Create or Update Agency"
description: "Create an agency if missing, otherwise merge provided fields"
openapi: "POST /agency"
---

<Note>
`name` is required when creating. Fields like `userId`, `ID`, `ts`, and `secret` cannot be overwritten via the body.
</Note>

## Example Request

```json
{
  "agency": {
    "name": "Acme Agency",
    "brandingText": "Powered by Acme",
    "supportEmail": "support@acme.example",
    "mainWebsite": "https://acme.example"
  }
}
```
