---
title: "Change Client Password"
description: "Change a client dashboard password after verifying the current one"
openapi: "POST /clients/{clientId}/change-password"
---

## Example Request

```json
{
  "oldPassword": "CurrentPassw0rd!",
  "newPassword": "NewStrongPassw0rd!"
}
```

<Note>
`newPassword` must be at least 12 characters and pass password strength validation.
</Note>
