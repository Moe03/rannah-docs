---
title: 'Get Workspaces'
description: 'Retrieves all workspaces accessible to the authenticated user, this route must use the new V3 [endpoints](/api-reference/v3/intro).'
openapi: 'GET /workspaces'
---

<Note>
Returns all workspaces where you are either the owner or a team member.
</Note>

<Tip>
Use this endpoint to list available workspaces before switching context or managing team members.
</Tip>
