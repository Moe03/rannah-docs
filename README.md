# Rannah رنّة Documentation

Public Mintlify documentation for [Rannah رنّة](https://rannah.io).

## Preview locally

```bash
mintlify install
mintlify dev
```

Open the URL Mintlify prints (default `http://localhost:3000`).

## Deploy

Connect this repository to [Mintlify](https://mintlify.com) and point your docs domain (e.g. `docs.rannah.io`) at the deployment.

## Structure

- `docs.json` — Mintlify navigation and branding
- `help-center/` — Getting started guides
- `agent-creation/`, `canvas/`, `features/`, etc. — Product documentation
- `images/`, `assets/`, `logo/` — Static assets
