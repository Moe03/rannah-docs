# Pricing Overview

Transparent, capability-based pricing. The **v2-2026** plan ladder (and its feature gates) applies to **new users only**.

<Note>
  **Existing customers (any plan before August 2026):** if you were already on an older plan — classic Pay as you go, legacy, managed, or any pre–August 2026 catalog — you keep **all features unlocked**. Nothing is taken away; you are not migrated onto the new ladder. The tier limits below apply only to new / never-paid workspaces on `v2-2026`.
</Note>

<Note>
  **Credits are simple:** **1 USD = 1,000 credits**.

  Plan prices below are in USD. Annual billing is ~33% off (**4 months free** — pay for 8 months, get 12).
</Note>

<Tip>
  Compare plans on the [public pricing page](/Pricing/overview) or open **Billing** in the dashboard (bottom left) to upgrade, add add-ons, or buy credits.
</Tip>

## Who sees which catalog?

| Cohort | Plans / access | Notes |
|--------|----------------|--------|
| **New users (Aug 2026+)** | Free → Starter → Pro → Business → White Label → White Label Elite | Catalog id `v2-2026` — feature gates by tier |
| **Any older plan (pre–Aug 2026)** | Your existing plan stays | **All features remain unlocked** — PAYG, legacy, managed, and other pre-v2 catalogs are fully grandfathered |

Public REST API access on v2: **Business+** (read), **White Label+** (write). See [API Authentication](/Support/contact). Grandfathered pre–August 2026 paid workspaces keep their existing API access.

## What’s included by tier

### Free — $0
Sandbox to learn the product.
- Web widget, tools/nodes builder, basic analytics
- 2 agent slots, 1 workspace seat, 2 trial client seats
- Tier 4 AI models (fast / value)
- One-time 500-credit trial

### Starter — $29/mo
Early production on web + Telegram.
- Everything in Free (with monthly credits)
- Telegram channel
- Calendar & email integrations
- Tier 3+ models
- Community / email support

### Pro — $59/mo (most popular)
Full inbound omnichannel chat.
- Everything in Starter
- All chat channels (WhatsApp, Instagram, Messenger, Discord, Email)
- Live handoff + ticketing, lead funnel, CRM integrations
- Widget tabs, standard analytics
- Overage credits (buy more when you need them)
- Tier 2+ models
- Monthly crawler refresh

### Business — $99/mo
Proactive growth — voice, campaigns, unbranded widget.
- Everything in Pro
- Voice / phone (SIP + Twilio), realtime call listening
- Remove Rannah رنّة widget branding
- Campaigns + AI follow-ups, AI summarization
- BYOK + premium (Tier 1) models
- MCP + webhooks, agent simulator
- KB crawler access + auto-update
- Public API **read** access
- 2 Twilio numbers + 3 concurrent call lines included
- Weekly crawler refresh · Priority email support

### White Label — $199/mo
Agency platform.
- Everything in Business (API upgrades to **full** write)
- Per-client analytics, crawler proxy + auto-scrape
- Unlimited agents, 10 workspace seats, 20 client seats
- 3 Twilio numbers + 10 concurrent lines
- Daily crawler refresh · Priority + onboarding support

### White Label Elite — $349/mo
SaaS mode for agencies.
- Everything in White Label
- SaaS mode, client self-signup, client-facing analytics
- Unlimited workspace & client seats, unlimited KB docs
- Rebrandable API
- Agency auto-billing (Stripe Connect for clients)
- 5 Twilio numbers + 25 concurrent lines · Dedicated support

Need a custom enterprise deal (on-prem, dedicated build, custom SLAs)? Contact sales from the [pricing page](/Pricing/overview).

## Voice call pricing

Total ≈ **platform fee + STT + TTS (or realtime STS) + LLM + telephony (optional)**.

| Component | Typical range |
|-----------|----------------|
| Platform fee | **$0.020/min** (20 credits) |
| Speech-to-Text | $0.004 – $0.013/min |
| Text-to-Speech | $0.010 – $0.070/min |
| Realtime STS | $0.010 – $0.070/min (Gemini Live / Ultravox / Grok Live) |
| LLM | Varies by model (BYOK on Business+) |
| Twilio | ~$0.015/min (est.) |

Voice / phone access starts on **Business** (or the Voice add-on).

## Cost optimization tips

1. Start on the right tier — don’t buy Business if Pro channels are enough; use add-ons for one missing feature.
2. Prefer Tier 4 / Tier 3 models for high-volume FAQ traffic.
3. Enable **BYOK** on Business+ to cut LLM credit burn.
4. Disable widget autostart / initial prompt if you don’t need proactive chat.
5. Use Speechmatics / Google STT + Google TTS, or Gemini Live, for budget voice stacks.
