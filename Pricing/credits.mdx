## How Credits Work

- **Allocation**: Free workspaces get a **one-time 500-credit trial**. Paid v2 plans include monthly credits (Starter 5k → Elite 120k). You can buy top-ups from Billing (overage on Pro+).
- **Consumption**: Each feature or service consumes credits based on complexity (base interaction + model tokens + voice/crawl, etc.)
- **Balance tracking**: Monitor usage in the dashboard (quota banners + Billing)
- **Transparency**: Credit costs are defined below so you know what you're paying for
- **Rollover**: Unused monthly credits (including purchased top-ups) carry to the next billing cycle. Each cycle adds your plan’s monthly quota on top of your remaining balance.

## Saving credits & optimizing usage

One of our users complained credits were being consumed quickly. By changing the following 2 settings, we decreased about 95% of their credits usage:

### 1. Use the latest widget code
The legacy widget code uses an expensive CDN, prompting us to charge a small amount of credits on every visit. The new script uses a different, more efficient CDN (vg-bunny, which is the current latest), thus saving a significant amount of credits.

### 2. Disable autostart & initial prompt
The autostart feature combined with initial prompt can drain credits quickly — for every visit you can spend up to 50 credits if the prompt & output are long.

**By disabling autostart:**
- You save 1 credit fee for the base fee of the interaction

**By disabling the initial prompt:**
- You save up to 100 credits per visit since you're not going to prompt the AI unless the user explicitly asks for it
- By default, the autostart option is off for this reason
